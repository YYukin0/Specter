# 概念学习资源（YouTube）— 2026-08-28

按「先看哪个」的顺序整理，覆盖 [[project_plan_v9]] 里五大支柱涉及的基础概念。
3Blue1Brown 两集是这个领域播放量最高、最经典的入门（attention 那集 4M+ 播放）。

**建议节奏**：第 0、1 块务必先啃透（判断力的基础）；第 2、4 块对应已动手的 M2 和量化部分，边看边对代码；第 3、5、6 块按需查。

## 0. 打地基：LLM 是怎么生成文字的

- [Transformers, the tech behind LLMs (3Blue1Brown)](https://www.youtube.com/watch?v=wjZofJX0v4M) — token、embedding、逐 token 预测下一个词的概率分布。看懂这个才懂投机解码在「抢跑」什么。
- [Attention in transformers, step-by-step (3Blue1Brown)](https://www.youtube.com/watch?v=eMlx5fFNoYc) — Q/K/V、softmax、causal mask。P1.1 的「目标模型单次前向对全部候选打分」依赖这个机制。

## 1. 为什么推理慢（项目统一原理：内存带宽 vs 计算瓶颈）

整个项目的「一套系统原理」，必须看懂。

- [Why LLM Inference Is Memory-Bound, Not Compute-Bound](https://www.youtube.com/watch?v=ADVRuiJSxWw) — 解码阶段每生成 1 个 token 要把整个模型权重从显存搬一遍，算力大量闲置。投机解码和量化能加速的根本原因。
- [LLM Inference Lecture: Roofline Analysis for GPU](https://www.youtube.com/watch?v=7EJjdDLK4cg) — roofline 模型、arithmetic intensity、compute-bound / memory-bound 分界。batch size 交叉点实验（支柱4）就是在找这条分界线。
- [KV Cache in LLMs Explained Visually](https://www.youtube.com/watch?v=7OrMFn86PlM) 或 [KV Cache: Prefill and Decode](https://www.youtube.com/watch?v=hafEw3bEu8E) — prefill vs decode 两阶段、KV cache 为什么随序列变长。

## 2. 支柱1：投机解码

- [Speculative Decoding: The ONLY Video You Need to Speed Up Inference](https://www.youtube.com/watch?v=_hEGvCwHyH8) — 小模型 draft、大模型一次性 verify、2–3x 加速的直觉。
- [Speculative Decoding explained](https://www.youtube.com/watch?v=p23SblAIoXc) — 配套可视化。
- 概念对照：看完后，项目里的 γ（每轮草稿几个 token）、接受率 α、bonus token 就能对上号。

## 3. 采样与「正确性验证」（P1.2 / P1.3）

- [LLM Decoding Strategies: Greedy, Beam, Top-k, Top-p, Temperature](https://www.youtube.com/watch?v=JqgsxC4guK4) — 贪心解码（北极星指标：逐 token 100% 一致）和采样模式（要验证分布等价）的区别。
- 投机解码里的 rejection sampling（接受判据 + 从调整分布重采样）本质是「如何用草稿模型的样本模拟目标模型分布」，看懂 temperature/top-p 后这段公式会好读很多。

## 4. 支柱2：量化（AWQ / GPTQ / 4-bit）

- [LLM Quantization Explained: GPTQ, AWQ, QLoRA, GGUF and More](https://www.youtube.com/watch?v=WmvZwR4rKJg) — 有分章节，PTQ vs QAT、各方法区别。
- [LLM Quantization Techniques Explained - GPTQ AWQ GGUF HQQ BitNet](https://www.youtube.com/watch?v=0pF6GdbwMo4) — 先看它前一集讲 linear quantization 基础，再看这集讲 AWQ「用激活值幅度决定哪些权重通道要保护」——正好是 P2.1 逐通道缩放校准的核心思想。

## 5. 评测指标：Perplexity

- [Evaluating language models using perplexity (NLP817)](https://www.youtube.com/watch?v=72eVFb7USKs) — 判断量化好不好（perplexity 涨幅 <5%）、跨分布鲁棒性实验（P2.2）全靠这个数。理解成「模型平均在多少个词里犹豫」。

## 6. 支柱5：自适应控制器（BanditSpec 相关）

- [Multi-Armed Bandits: A Cartoon Introduction](https://www.youtube.com/watch?v=bkw6hWvh_3k) 或 [Multi-Armed Bandit: Data Science Concepts](https://www.youtube.com/watch?v=e3L4VocZnnQ) — exploration/exploitation 困境。项目不重新实现 BanditSpec，但要跑它做基线，得知道它在解决什么问题：「每一步该让草稿模型猜几个 token」就是一个多臂老虎机式的决策。
